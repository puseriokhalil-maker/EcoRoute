SETUP

Git and GitHub Setup

Follow the commands below to connect your local EcoRoute project to the group's GitHub repository and prepare your computer for team collaboration.

1. Configure Your Git Identity

Set your name and email address before making commits. 

git config --global user.name "Your Name"
git config --global user.email "email@example.com"

2. Clone the EcoRoute Repository

Clone the team's GitHub repository to your computer. 

git clone https://github.com/puseriokhalil-maker/EcoRoute.git
cd EcoRoute

3. Check the GitHub Connection

Verify that your local project is connected to the correct remote GitHub repository. 

git remote -v

The result should display: 

origin  https://github.com/puseriokhalil-maker/EcoRoute.git (fetch)
origin  https://github.com/puseriokhalil-maker/EcoRoute.git (push)

4. Create Your Own Branch

Each member should work on a separate branch instead of directly modifying the main branch. 

git switch -c setup-page

Replace setup-page with the name of your assigned feature or task.

5. Check Your Changes

After editing your files, use Git status to see what has changed. 

git status

6. Stage Your Changes

Add your modified files to the staging area. 

git add .

7. Commit Your Changes

Create a commit with a clear message describing your work. 

git commit -m "Create Git setup page"

8. Push Your Branch to GitHub

Upload your branch to the EcoRoute GitHub repository. 

git push -u origin setup-page

9. Update Your Local Main Branch

Before starting another task, switch to the main branch and download the latest changes. 

git switch main
git pull origin main

10. Create a Pull Request

After pushing your branch, open the EcoRoute repository on GitHub and create a Pull Request.

  1. Open the EcoRoute repository on GitHub.
  2. Select your recently pushed branch.
  3. Click Compare & pull request.
  4. Describe the changes you made.
  5. Ask another group member to review your work.
  6. Merge the Pull Request after approval.

Complete Setup Example

The following shows the typical command sequence for a team member starting work on EcoRoute. 

git clone https://github.com/puseriokhalil-maker/EcoRoute.git

cd EcoRoute

git switch -c feature-name

git status

git push -u origin feature-name

EcoRoute GitHub Repository

All team members should use the same remote repository:

https://github.com/puseriokhalil-maker/EcoRoute.git

Important Team Rules

Use Branches

Do not make feature changes directly on the main branch.

Pull Before Coding

Always update your local main branch before starting new work.

Review Before Merge

Pull Requests should be reviewed by another member before merging into main.
