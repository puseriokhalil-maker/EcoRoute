Getting the EcoRoute Repository

git clone https://github.com/puseriokhalil-maker/EcoRoute.git

Steps for Working on a Task

  1. Switch to the main branch. 
    git switch main
  2. Download the latest project updates. 
    git pull origin main
  3. Create a branch for your assigned task. 
    git switch -c feature-workflow
  4. Make the required changes and test your work in VS Code.
  5. Check your current branch and modified files. 
    git branch
git status
  6. Review the changes before committing. 
    git diff
  7. Stage the completed changes. 
    git add .
  8. Create a commit that describes your work. 
    git commit -m "Add team workflow page"
  9. Push your feature branch to the EcoRoute repository. 
    git push -u origin feature-workflow
  10. Create a pull request on GitHub.
  11. Have another team member review the changes before merging.
  12. Return to the main branch and get the latest version after the merge. 
    git switch main
git pull origin main

EcoRoute Team Rule

Always update the main branch first, create a separate feature branch, complete and test your task, review the changes, commit and push your work, then submit it for team review before merging it into main.
